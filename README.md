# Multi_Source_Intelligence_Hub
 web application that allows users to ask questions about PDF documents and access GitHub information through a single dashboard.

Features

PDF upload and question answering

Answers with page citations

Chat history

GitHub integration

Analytics dashboard

Technologies Used

Python, Flask

HTML, CSS, JavaScript

ChromaDB, Sentence Transformers

Google Gemini API

PyMuPDF

MySQL

How to Run

Install dependencies:
pip install -r requirements.txt

Configure your API keys and database settings in .env.

Run the application:
python app.py

Open the local URL shown in the terminal.

Testing

All main features have been tested locally.

Security

Keep API keys and passwords private. Never upload .env to GitHub.
